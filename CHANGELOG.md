# Changelog

## 0.10.0
- New look: slate paper, ink text, one magenta accent, Newsreader for reading and Hanken Grotesk for headings, soft rounded corners, light and dark.
- AI Roundtable: any number of AIs, a chosen number of debate rounds, moderator guidance before each round that you can edit, skip to verdict, table setup during a session, share the transcript.
- Book cover: choose any of the book's pictures, automatic, or a plain cloth cover.
- Edit with AI: Send and Accept moved to the top bar so they are never hidden below a long selection.
- AI history shows picture requests with their pictures.
- Fixes: ChatGPT's new page layout (reply capture and document blocks), prompts lost when a site reloads, a missed send button press, a previous draft left in a new chat's box, Perchance keeping its old prompt, sites that reject long messages now say so.

## 0.9.x

- "Before typing" teach step for sites that need a mode button pressed first.
- Library views: bookshelf, grid and list.
